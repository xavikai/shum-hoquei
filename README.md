# SHUM · Hoquei patins

Web pública del club per a la temporada 2026/27: tots els equips del SHUM, amb calendari, resultats, classificació, rànquings i alineacions de les actes de FECAPA, i els vídeos dels partits de l'Infantil Or. És només de consulta.

Web: https://xavikai.github.io/shum-hoquei/

Executa `node --test tests/*.test.mjs` i `node scripts/build-pages.mjs`. Cada push a main publica a GitHub Pages amb GitHub Actions. Les dades de FECAPA i els vídeos s'actualitzen automàticament. Vegeu [GITHUB_PAGES.md](GITHUB_PAGES.md).
