# SHUM Infantil Or

Web de la temporada 2026/27: calendari, resultats, alineacions, entrenadors, rànquings i anàlisi de vídeos.

Web: https://xavikai.github.io/shum-infantil-or/

Executa `npm run check` i `npm run build`. No cal instal·lar dependències. Cada push a main publica a GitHub Pages amb GitHub Actions.

Les anàlisis es desen i recuperen en fitxers JSON. No hi ha sincronització automàtica entre dispositius. Les dades desconegudes (minuts, edats, targetes) es mostren com a pendents. Vegeu [GITHUB_PAGES.md](GITHUB_PAGES.md).
