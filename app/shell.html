SHUM · HOQUEI PATINS

Instal·la la web al mòbil

Tindràs la icona del SHUM a la pantalla d’inici per obrir el calendari, els resultats i els vídeos.

Android / Xiaomi

  1. Obre aquesta web amb Chrome.
  2. Toca Instal·la l’app i confirma la instal·lació.
  3. Si no apareix la finestra, obre el menú ⋮ de Chrome i tria Afegeix a la pantalla d’inici o Instal·la l’aplicació.

iPhone / iPad

  1. Obre aquesta web amb Safari.
  2. Toca Comparteix i Afegeix a la pantalla d’inici.
  3. Si apareix l’opció Obre com a app web, activa-la i toca Afegeix.

Si estàs dins d’una altra aplicació, obre l’enllaç a Chrome o Safari. Necessites connexió a Internet per consultar les dades i els vídeos.
